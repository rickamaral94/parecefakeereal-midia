# parecefakeereal-midia

Vídeos e código de produção dos Reels do Instagram @parecefakeereal.

- `videos/` — Reels finais (9:16, narração sintética PT-BR, legendas). Hospedados aqui para publicação via integração.
- `src/` — motor de renderização (`engine.py`), roteiros de cada Reel e legendas de publicação (`captions.json`).

Narração: voz Piper `pt_BR-faber-medium`. Animações esquemáticas autorais, sem imagens de terceiros.
